## Sobre mim

Analista de Suporte Jr. e estudante de Engenharia de Software. Minha base vem de suporte, infraestrutura, redes e troubleshooting; hoje direciono essa experiência para desenvolvimento backend, automação e observabilidade.

Gosto de construir ferramentas que transformam rotinas operacionais em processos mais rastreáveis, mensuráveis e automatizados. Também estudo aplicações de IA e Machine Learning voltadas para operações de TI.
